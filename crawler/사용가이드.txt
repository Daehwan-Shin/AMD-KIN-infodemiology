========================================================
  네이버 지식iN 크롤러 사용 가이드
========================================================

네이버 지식iN에서 원하는 키워드로 질문/답변 데이터를
수집하고 Excel로 내보내는 크롤러입니다.
(기본 키워드: 황반변성)


--------------------------------------------------------
  1. 설치
--------------------------------------------------------

[1-1] Python 설치

  Python 3.13 이상이 필요합니다.
  - https://www.python.org/downloads/ 에서 다운로드
  - 설치 시 "Add Python to PATH" 반드시 체크


[1-2] 패키지 설치

  명령 프롬프트(cmd)를 열고 이 폴더로 이동한 뒤 실행합니다.

    pip install -r requirements.txt


[1-3] Playwright 브라우저 설치

    playwright install chromium


[1-4] 네이버 API 키 설정 (선택)

  collect_urls.py를 사용할 경우에만 필요합니다.
  crawl_all.py만 사용하면 이 단계는 건너뛰어도 됩니다.

  1) .env.example 파일을 복사하여 .env 로 이름 변경
  2) https://developers.naver.com 에서 애플리케이션 등록 후
     Client ID / Secret 발급
  3) .env 파일에 발급받은 키 입력


--------------------------------------------------------
  2. 실행
--------------------------------------------------------

[기본 실행] 기본 키워드(황반변성)로 전체 기간 크롤링

    python crawl_all.py


[키워드 지정] 다른 키워드로 크롤링

    python crawl_all.py --keyword "녹내장"
    python crawl_all.py --keyword "백내장"


[기간 지정] 특정 기간만 크롤링

    python crawl_all.py --keyword "황반변성" --date-from 20250101 --date-to 20250131


[건수 제한] 테스트용

    python crawl_all.py --keyword "황반변성" --date-from 20250101 --date-to 20250131 --limit 10


[이어서 하기] 이전 크롤링 재개

    python crawl_all.py --resume


[처음부터] 기존 데이터 무시하고 새로 시작

    python crawl_all.py --fresh --keyword "황반변성" --date-from 20250101 --date-to 20250131


[Excel만 다시 내보내기] 이미 크롤링한 데이터로 Excel 재생성

    python export.py
    python export.py --keyword "녹내장"


--------------------------------------------------------
  3. 실행 과정
--------------------------------------------------------

크롤러는 3단계로 동작합니다.

  [Step 1/3] URL 수집
    - kin.naver.com 검색 페이지에서 질문 URL 목록 수집
    - 주 단위로 기간을 나누어 검색

  [Step 2/3] 본문 크롤링
    - 수집된 URL을 하나씩 방문하여 질문/답변 내용 수집
    - 3~7초 간격으로 요청 (차단 방지)
    - 10건마다 진행 상황 자동 저장
      (중간에 중단해도 --resume으로 재개 가능)

  [Step 3/3] Excel 내보내기
    - 수집된 데이터를 Excel 파일로 변환


--------------------------------------------------------
  4. 결과 파일
--------------------------------------------------------

실행이 끝나면 data\output\ 폴더에 결과가 저장됩니다.

  data\
    output\
      [키워드]_지식인_YYYYMMDD_HHMMSS.xlsx    <-- 최종 결과
    raw\
      123456789.json                          <-- 개별 크롤링 원본
    pw_urls.json                              <-- 수집된 URL 목록
    pw_progress.json                          <-- 크롤링 진행 상황


[Excel 컬럼 설명]

  url                      지식iN 질문 링크
  question_title           질문 제목
  question_content         질문 내용
  question_author          질문 작성자
  question_date            질문 작성일
  question_views           조회수
  category                 카테고리/태그
  answer_count             답변 수
  answer_1_content         답변 1 내용 (최대 10개까지)
  answer_1_author          답변 1 작성자
  answer_1_date            답변 1 작성일
  answer_1_adopted         답변 1 채택 여부


--------------------------------------------------------
  5. 참고 사항
--------------------------------------------------------

- 크롤링 속도는 건당 3~7초입니다.
  1,000건 기준 약 1~2시간 소요됩니다.

- 중간에 창을 닫거나 Ctrl+C로 중단해도
  --resume 옵션으로 이어서 할 수 있습니다.

- 검색 키워드를 변경하려면 --keyword 옵션을 사용하면 됩니다.
  예) python crawl_all.py --keyword "녹내장"
  --keyword를 생략하면 기본값 "황반변성"으로 검색합니다.
